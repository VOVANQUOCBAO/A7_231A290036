# Lab A7 - Xin quyền truy cập tài nguyên

**Họ tên:** Võ Văn Quốc Bảo

**MSSV:** 231A290036

**Học phần:** INT4211 - Lập trình trên các thiết bị di động

## Nội dung

- Xin quyền CAMERA và chụp ảnh xem trước.
- Xử lý cho phép, từ chối, giải thích và mở Cài đặt khi bị chặn.
- Xin quyền POST_NOTIFICATIONS trên Android 13 trở lên và gửi thông báo.
- NC3: chạm thông báo để mở lại ứng dụng.
- NC4: sơ đồ luồng xin quyền trong báo cáo.

## Cách chạy

1. Mở thư mục `A7_231A290036` bằng Android Studio.
2. Chờ Gradle Sync, chọn module `app`.
3. Chọn máy ảo hoặc điện thoại Android API 24 trở lên và bấm **Run**.

Project sử dụng Java + XML, Java 17 và compileSdk 35.

Dùng máy Android 13 trở lên để thử hộp thoại quyền thông báo. Máy ảo cần bật camera trong Device Manager.
